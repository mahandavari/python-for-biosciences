# Start here

1. Read [setup/README.md](setup/README.md) in its stated order. Get the full course folder, install/check Python and VS Code, then run the ready-message script.
2. Open [Session 01](sessions/01/README.md). Read its live guide and lesson, run the demo, do practice, take the short assessment and complete homework. Scripts are enough today.
3. Before Session 02, complete [notebook setup](setup/03_NOTEBOOKS.md). Check a real code cell with your selected Python kernel.
4. Open [Session 02](sessions/02/README.md). Follow its notebook in order, run the GC script at the stated point, then practice, assessment and homework. Use solutions after an attempt.
5. Continue in order: [Session 03](sessions/03/README.md) validates numeric counts; [Session 04](sessions/04/README.md) counts DNA characters and searches motifs; [Session 05](sessions/05/README.md) analyzes several named DNA strings. Start each README, then its guide and notebook. Run 02_DEMO.py during the main build block. Attempt 04_EXERCISES.md and 07_ASSESSMENT.md, then complete 05_HOMEWORK.md after class. Open solutions/06_SOLUTIONS.md only after an attempt.
6. Use [troubleshooting/checklist](setup/04_TROUBLESHOOTING_AND_CHECKLIST.md) if blocked. Offline: read downloaded notes and expected outputs, record predictions and errors, then retry execution when ready.
7. Continue with [Session 06](sessions/06/README.md): functions, a two-file import example and VS Code debugging. Follow the README and lesson for the order of scripts, checks and repair practice.
8. Open [Session 07](sessions/07/README.md) for files and reports. Keep [datasets](datasets/README.md) in place. Follow its portable script instructions; generated outputs go under the working directory's outputs folder.
9. Before [Session 08](sessions/08/README.md), read its [environment guide](sessions/08/02_ENVIRONMENT.md). Run the notebook with the same interpreter used for pip. Attempt practice and assessment, complete homework after class, then inspect separate solutions.
10. Open [Session 09](sessions/09/README.md). Follow its guide and notebook; run the demo, attempt classroom charts and assessment, then complete the three-chart homework before viewing solutions.
11. Open [Session 10](sessions/10/README.md). Follow the Seq/SeqIO notebook, run the demonstrations and small guided workflow, then review progress and submission steps.
12. Start [the final project](final-project/00_START_HERE.md). Read the specification and rubric, complete the TODO starter, run your tests, inspect output and submit the requested files. The full project is homework.

Sessions 01-10 and the final project assignment are available. Shared datasets are included; all are synthetic educational text files. No external dataset download is needed. [Assets](assets/README.md) records the original diagrams and reuse terms.

The repository has not been published yet. Use the teacher-supplied local folder until the teacher provides the verified public link. Keep folders together so relative links work. Homework submission uses the channel named by the teacher; no submission service is built into this folder.
