# Setup reading order

Use Windows 10/11, standard Python and VS Code. No programming experience, Git commands or Anaconda needed.

1. [Meet the tools and get the course folder](01_TOOLS_AND_DOWNLOAD.md).
2. [Install/check Python and VS Code; run a script](02_WINDOWS_PYTHON_AND_VSCODE.md).
3. [Prepare Jupyter notebooks](03_NOTEBOOKS.md) before Session 02, not required for Session 01.
4. [Troubleshooting and pre-class checklist](04_TROUBLESHOOTING_AND_CHECKLIST.md).

Read in order before class. Initial software downloads need internet; keep the extracted folder for offline study. Full environment/package instruction stays in Session 08.

Course code was tested on Windows with Python 3.12.14 and ipykernel 7.4.0. The Python 3.13 installer route is based on official sources, but was not installed on this authoring machine; a new student installation must pass the checks. The Python Windows downloads and Windows guide, and the VS Code kernel guide, were checked on 2026-10-22. Screens and package releases may change.
