# 1. Meet the tools and open the course folder

You do not need programming experience. Read this guide before installing anything.

## What each tool does

| Word | Meaning | Example |
| --- | --- | --- |
| Programming language | A way to write precise instructions for a computer | Python |
| Python | The language used in this course; also the name used for its interpreter | `print("Hello")` is a Python instruction |
| Interpreter | The program that reads and runs Python instructions | It turns the instruction into visible output |
| Code | Instructions written in a programming language | A line that prints a message |
| Syntax | Rules for writing those instructions | Text needs matching quotation marks |
| Code editor | A program for writing and saving code | VS Code |
| VS Code | Our editor; it shows files, code, terminals and notebooks | It does not replace the Python interpreter |
| Terminal | A text area where you ask the computer to run commands | PowerShell in VS Code |
| Script | A saved Python text file ending in `.py` | Run the whole file from top to bottom |
| Jupyter Notebook | A document ending in `.ipynb` with explanations and runnable code | Used from Session 02 |
| Cell | One block of notebook text or code | Run a code cell to see its output below |
| Kernel | The running Python process serving a notebook | It remembers variables until restarted |
| Extension | An editor add-on | Microsoft's Python and Jupyter extensions |
| Package | Extra Python code that can be installed | `ipykernel` connects Python to notebooks |

VS Code is the writing desk. Python runs the instructions. Jupyter gives us a document made of cells; its Python kernel runs the code. Installing an extension does not install every Python package.

## Get the course files

GitHub is a website for storing and sharing projects. A repository is a project's collection of files and changes. You do not need Git or a GitHub account to download a public ZIP.

**The course repository is not published yet. Use only the public course link verified and supplied by the teacher.** For now, use the local `student-course` folder supplied by the teacher. Do not search for an unofficial copy.

When the teacher supplies the published URL:

1. Open that repository's main page. Above its file list, find **Code** (often a green button).
2. Choose **Code > Download ZIP**. If a page shows only one file, return to the repository main page first.
3. In Windows File Explorer, find the ZIP in Downloads. Right-click it, choose **Extract All**, select a folder you can find again, then select **Extract**.
4. Open the extracted folder, not the compressed ZIP. There may be one extra outer folder. Find the folder containing `00_START_HERE.md`, `setup` and `sessions`.
5. In VS Code, choose **File > Open Folder** and select that folder. Trust it only if you know it came from the teacher or the official course source.

Local alternative: copy the supplied `student-course` folder to a writable study folder, then open that copy in VS Code. Keep all subfolders together. Opening the whole folder makes lesson links and assets work and helps the terminal start in the right place.
