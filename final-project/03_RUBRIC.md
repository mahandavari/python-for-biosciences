# Assessment rubric

| Weight | Category | What earns credit |
| --- | --- | --- |
| 35% | Python fundamentals and program structure | Clear variables, conditions, loops, collections and student-authored small functions; explain the flow and avoid repeated core code. |
| 15% | File handling and output | Multi-record/wrapped FASTA, identity/order preserved, exact CSV fields and portable input/output paths. |
| 15% | Algorithmic and biological correctness | Exact base counts and length, guarded GC, exact overlapping zero-based motif starts, documented alphabet. |
| 10% | Data visualization | Two suitable saved plots with correct values, labels, units, scale and readable text. |
| 10% | Error handling and testing | Useful failures, no silent skipping, independent valid/edge-case tests, no damaged reports on invalid input. |
| 10% | Documentation and reproducibility | Exact run steps, dependencies, motif/input choices, reproducible outputs and readable comments. |
| 5% | Scientific interpretation and limitations | Synthetic provenance and descriptive claims only; explain alphabet, strand, motif and GC limitations. |

Total 100%. Partial credit follows demonstrated working features and explanations
in each category. A copied program without explained student-authored calculations
cannot earn full fundamentals credit. Test against the same default file/motif and
test plan for every submission; record category points and concrete feedback.
