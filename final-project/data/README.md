# Synthetic DNA fixtures

Created for this course on 2026-10-22 by direct letter choice; CC0 1.0.
No organism, experiment or external download. One represented DNA strand per ID;
header descriptions explicitly mark synthetic provenance. Length unit: bases.
sequences.fasta varies length/composition, wraps lines and includes lowercase.
single.fasta is one record. invalid.fasta intentionally contains N, outside this
project's simplified alphabet. duplicate.fasta repeats first-token ID Same with
different descriptions. empty.fasta has zero bytes; empty_record.fasta has an empty
sequence; no_header.fasta is malformed. These are deliberate test cases, not data
to silently skip. Expected numerical results are in ../02_EXPECTED_RESULTS.md.
