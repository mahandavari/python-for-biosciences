# Submission checklist

Submit one ZIP through the teacher's stated channel. Include analyzer.py, checks.py
(or your extended 05_CHECKS.py), README.md with exact environment/run instructions,
your synthetic input FASTA, report.csv, gc_by_id.png and length_vs_gc.png, and a
short interpretation.md. Keep the input beside the script under data/ and explain
how you reproduced your output from the course root. State the motif and package
versions, known limits, tests actually run and their outcomes.

Before submitting: restart/run your program, check all expected rows, run your tests,
inspect the two PNGs, rerun and compare. Explain one algorithm in your own words.
Interpret what each plot shows, why its type fits, what can be said descriptively
and what cannot be concluded. Explain that all sequences are synthetic.
Do not submit .venv, caches, VS Code settings, the whole course, private teacher
files, credentials, or unrelated data. No GitHub publication is required.
