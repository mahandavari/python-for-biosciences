Follow [01](01/README.md), [02](02/README.md), [03](03/README.md), [04](04/README.md), [05](05/README.md), [06](06/README.md), [07](07/README.md), [08](08/README.md), [09](09/README.md) and [10](10/README.md) in order. Start each README, then the live guide and lesson. Run the stated scripts, attempt classroom exercises and assessment, finish homework, then open separate explained solutions. Session 01 uses notes/scripts; Sessions 02-10 also use notebooks.

The sequence is first script (01), numeric counts and Jupyter (02), validation (03), DNA strings/loops/motifs (04), collections (05), reusable functions/debugging (06), file reports/errors (07), environments/NumPy/Pandas (08), Matplotlib visualization (09), and introductory Seq/SeqIO plus an initial integrated program (10). Each lesson runs independently; keep the [synthetic datasets](../datasets/README.md) in place.

After Session 10, complete the [DNA Sequence Analyzer](../final-project/00_START_HERE.md) as homework. Its complete reference solution is not included. Use the updated course requirements for the scientific sessions. No slides or online biological services are required.
