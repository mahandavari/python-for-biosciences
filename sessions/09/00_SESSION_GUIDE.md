# Session 09 live guide

Scientific Data Visualization. Exactly 120 contiguous minutes.

| Time | Locked topic and screen demonstration | Student checkpoint and pause |
| --- | --- | --- |
| 00-10 | Review. Reopen a small Pandas table and inspect columns/missing values (5). | Recall metadata versus numeric values and missing versus zero (5). |
| 10-25 | Selecting appropriate charts, axes and units. Start with the gene-measurement question; compare category, distribution, time and paired-value questions (9). | Task 1: choose charts and label axes; discuss/pause (6). |
| 25-50 | Matplotlib, figures, axes, labels, saving figures. Build one Figure/Axes progressively; label and export PNG; display it (15). | Guided Task 2: predict values, add title, save and repair paths (10). |
| 50-70 | Bar plots and histograms. Compare category bars with adjacent numeric bins (12). | Task 3: hand-count bins and change bin width independently (8). |
| 70-85 | Line and scatter plots. Explain ordered time and paired measurements, including a missing time-point gap (9). | Tasks 4-5: trace the gap and identify paired points (6). |
| 85-110 | Visualization exercise with synthetic biological data. Restate CSV-to-plot steps and run portable script (5). | Task 6: guided bar setup (5), independent scatter/export/interpretation (10), compare and repair (5). |
| 110-120 | Improving charts and reviewing interpretation. Review zero baseline, units and missing data (3). | Assessment (4), review and homework (3). |

Teach from the notebook with enlarged text; one small cell at a time. Use chat, reactions or private notes, with no microphone/webcam requirement. Coding and repair time are inside these blocks. Stop repairs at the block boundary and offer the downloaded expected results. Homework is outside the live 120 minutes. The final practical uses commands already taught; it does not add a plotting library. No slides or internet data are needed. Restart Kernel, then Run All checks cell order; students may sketch expected graphs on paper and retry later if software is unavailable.
