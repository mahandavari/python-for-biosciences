Total: 120 contiguous minutes. Homework is outside class. Use screen sharing with a large font and one short cell visible at a time. Chat, reactions and private notes all count as participation; no webcam or microphone required.

If behind, read expected outputs in the notebook and predict results on paper. If only the kernel fails, run the matching script with the interpreter that works. Stop repairs at the checkpoint boundary and use the troubleshooting guide later. Downloaded notebook text, scripts, prompts and solutions support offline catch-up; initial installs need internet.
