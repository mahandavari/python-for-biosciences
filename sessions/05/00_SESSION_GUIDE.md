# Session 05 live guide

Python Data Structures. Open [the notebook](01_LESSON.ipynb) first. Outcome: structured summaries of multiple synthetic DNA sequences.
The topic labels and time boundaries below match the locked course schedule.

| Time | Learning purpose and screen demonstration | Student action/checkpoint | Expected result |
| --- | --- | --- | --- |
| 00-10 | Review. Trace one-sequence counters (3 min); compare motif count/positions (3); pause/check (4). | Recall count updates and valid alphabet. | Counters reset once for each sequence. |
| 10-30 | Lists and common list operations. Explain index/slice/append/remove (8); guided run (4); Practice 1-2/repair (8). | Add and remove synthetic DNA strings. | List changes; duplicates and order remain. |

| 65-80 | Iteration and simple nested structures. Walk keys/values and record (5); build nested lookup (4); Practice 7/pause (6). | Follow identifier to a summary field. | Two key lookups, not positional indexing. |
| 80-110 | Analyzing multiple synthetic DNA sequences. Plan and build script in parts (12); run/tie check (7); Practice 8/independent repair (11). | Store summaries; identify first longest/shortest. | Demo_A wins longest tie; Demo_B shortest. |
| 110-120 | Assessment and debugging. Repair tie/membership errors (3); assessment (4); review/homework (3). | Explain key membership and strict comparisons. | Equal lengths keep first accepted record. |

Total: 120 contiguous minutes. All demonstrations, coding pauses, independent tasks and repairs fit inside these blocks. Homework is outside class. Enlarge the font; reveal one small code cell at a time. Ask students to predict before running. Use chat, reactions or private notes; no microphone or webcam is required.

Stop repairs at the block boundary. Offline: use the downloaded notebook text, diagrams and expected outputs to trace the algorithm on paper. If only Jupyter fails, use the script. Record a specific blocker and retry after class. No live download or external data service is needed after setup.
