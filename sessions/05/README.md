# Session 05 - Python Data Structures

Exactly 120 live minutes. Prerequisites: Sessions 01-04: conditions, loops, DNA strings and validation. Outcome: structured summaries of multiple synthetic DNA sequences.
Open the complete course folder in VS Code. Select your Python kernel for notebooks.

1. [00_SESSION_GUIDE.md](00_SESSION_GUIDE.md): exact timing and checkpoints.
2. [01_LESSON.ipynb](01_LESSON.ipynb): read and run from the top during the webinar. Fixed inputs make Run All repeatable. Make a copy before edits.
3. [02_DEMO.py](02_DEMO.py): run with Run Python File in Terminal in the main build block. From the course root, use `python "sessions/05/02_DEMO.py"` (or your working `py` command). This script uses fixed data; edit a copy to try other records.
4. [04_EXERCISES.md](04_EXERCISES.md): attempt guided and independent tasks at the stated checkpoints in new cells or your own script.
5. [07_ASSESSMENT.md](07_ASSESSMENT.md): final timed block.
6. [05_HOMEWORK.md](05_HOMEWORK.md): outside class, with submission and self-check instructions.
7. [solutions/06_SOLUTIONS.md](solutions/06_SOLUTIONS.md): separate explanations and runnable answers after an attempt, including a solution notebook.

All biological inputs are synthetic educational examples. No earlier file needs to run first. If your kernel fails, read the notebook text and expected results, predict on paper, then use the script if Python works. Record the error and use [troubleshooting](../../setup/04_TROUBLESHOOTING_AND_CHECKLIST.md) after class.
