## Practice

1. Input: 10, 12, 14 mm. Process: add them, then divide by 3. Output: mean 12 mm. A rectangle shows a calculation; a parallelogram shows input/output.
2. Start, read lengths, add lengths (36 mm), divide total by 3 (12 mm), show mean, stop. There is no question or branching step, so no decision diamond is needed.
3. [03_PRACTICE_ANSWER.py](03_PRACTICE_ANSWER.py) prints two lines:

```text
I am learning Python.
I can find my course folder.
```

Each print displays its quoted text on a new line. Saving makes your latest code available when the file runs.

## Homework reference

[05_HOMEWORK_ANSWER.py](05_HOMEWORK_ANSWER.py) uses an invented nickname and sample interests. Its output is:

```text
My study nickname is Seed.
```

## Assessment key (five points)

1. Task = goal; algorithm = ordered precise steps to reach it.
2. Input = three lengths 10, 12, 14 mm; output = mean 12 mm.
3. The Python interpreter runs instructions. VS Code edits the file and can ask Python to run it.
4. `Ready` on one line, without quotation marks.
5. Check matching quotes first, then parentheses; save and rerun. A syntax error means Python could not read the instruction.

Review any missed idea in the lesson. Keep the operational check separate: correct quiz answers alone do not prove your environment works.
