# Session 01 live guide

Programming Fundamentals and Development Environment. Outcome: a working Python setup and a first executable program. Open [lesson notes](01_LESSON.md). All times are minutes from the start; pauses and repairs fit inside these blocks, not after them.

| Time | Learning purpose and screen demonstration | Student action/checkpoint | Expected result |
| --- | --- | --- | --- |
| 00-10 | Course introduction and programming in biology. Explain the course aim (3 min); show a repeated lab calculation (4 min); invite chat (3 min). | Name one repeated task, or write it on paper. | A concrete task, such as averaging three measurements; no prior biology needed. |
| 10-30 | Problems, algorithms, input/process/output, flowcharts. Explain task versus steps (5); show the local diagrams and symbols (7); guide input/process/output practice (5); pause/check (3). | Identify the input, process and output in Exercise 1. | Three values go in, add/divide is the process, one mean comes out. |
| 30-45 | Pseudocode and a biological measurement example. Work through fictional lengths (5); write pseudocode in plain text (4); independent reorder task (4); check (2). | Attempt Exercise 2; post the total or mean in chat. | Total 36 mm, mean 12 mm; steps in a clear order. |
| 45-75 | Python and VS Code installation checks, interpreter, terminal. Show installed Python/VS Code roles (5); verify interpreter and pip using setup guide (8); student check/repair pause (12); share results (5). | Run the version and ready-message checks; type `ready` or the short error. | Python version and `Python is ready`. Students behind switch to the printed expected output. |
| 75-90 | GitHub ZIP download, extraction, opening the folder. Show where Code > Download ZIP appears using the guide (4); demonstrate the already extracted local-folder alternative (4); extraction/open-folder practice (5); check (2). | Open the complete course folder and locate sessions/01. | Explorer shows README, lesson and demo together. No Git commands. |
| 90-110 | VS Code interface, creating and running the first .py file. Tour Explorer/editor/terminal (3); explain print syntax and run demo (5); guided then independent script practice (8); compare output/repair (4). | Save and run Practice 3; post one printed line. | A saved `.py` file and matching terminal output. |
| 110-120 | Troubleshooting and operational readiness check. Demonstrate one quote error and repair (3); assessment (3); final readiness check and homework directions (4). | Attempt the short assessment; confirm file saved, correct folder and a successful run. | Student can repeat the workflow, or has a specific blocker and catch-up plan. |

Total: 120 contiguous minutes. No notebook is required today. Homework is outside class.

Use Markdown preview (**Ctrl+Shift+V**) and enlarge the editor font for screen sharing. Show one file at a time. Students may respond by chat, a reaction, or private notes; cameras/microphones are optional. Never request a public screenshot containing private paths.

If installation is unfinished, stop repairs at the current block boundary. Read the local notes, predict outputs, and follow the demo. Record the exact error and retry with [troubleshooting](../../setup/04_TROUBLESHOOTING_AND_CHECKLIST.md) after class. If internet fails, the teacher uses the already extracted folder and saved diagrams; ZIP navigation can be rehearsed from the written guide.
