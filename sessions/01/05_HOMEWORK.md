# Session 01 homework: introduce yourself with a script

Outside class, open VS Code yourself, use File > Open Folder to open the extracted course folder, then create `01_introduction.py` in this session folder. Use three print instructions to show:

1. A study nickname (no private information needed).
2. A biology topic you want to learn about.
3. One repeated task that programming might help with.

Save and run the file. Check that three lines appear in the terminal and that the file ends in `.py`, not `.py.txt`. Submit **only `01_introduction.py`**, using the submission channel named by your teacher. Do not submit the entire course ZIP or an environment folder.

Success: you opened the folder independently, saved a runnable file and printed three meaningful lines. No variables, loops or calculations are required. If blocked, submit your saved attempt and a short error note through that same channel; repair it using the setup guide and rerun. A reference is in [solutions](solutions/06_SOLUTIONS.md), to read after attempting the work.
